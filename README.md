# Eunoia

Flutter application project, including static mobile-shell HTML prototypes aligned with the product UI.

## Root directory layout

| Name | Type | Description |
|------|------|-------------|
| `lib/` | Directory | Dart source: pages, routing, theme, services, and main Flutter app code. |
| `test/` | Directory | Unit and widget tests. |
| `android/` | Directory | Android platform project and Gradle configuration. |
| `ios/` | Directory | iOS platform project and Xcode-related configuration. |
| `web/` | Directory | Web build assets and entry resources. |
| `windows/`, `linux/`, `macos/` | Directories | Flutter host projects for each desktop platform. |
| `assets/` | Directory | Images, fonts, and other static assets (declared in `pubspec.yaml`). |
| `build/` | Directory | Build output from `flutter build`; avoid editing manually. |
| `.dart_tool/` | Directory | Dart/Flutter toolchain cache and generated files. |
| `.idea/` | Directory | JetBrains IDE (e.g. Android Studio) project settings. |
| `index.html` | File | **Primary UI prototype**: tabs for Practice / Community / Store / Profile inside a phone frame; from Store you can open the **Holographic Supply Pod**, including **figure pool / E-pet pool**, **single / ten-pull** animations, and demo E-point logic. |
| `index2.html` | File | **Design reference only**: deeper interactive prototype (word tower, legacy supply pod, etc.). Do not modify this file. |
| `pubspec.yaml` | File | Project metadata, dependencies, and asset declarations. |
| `pubspec.lock` | File | Locked dependency versions for reproducible builds. |
| `analysis_options.yaml` | File | Dart static analysis (analyzer / linter) rules. |
| `.metadata` | File | Flutter SDK version and channel metadata for the project. |
| `.gitignore` | File | Git ignore rules (build artifacts, local config, etc.). |
| `.flutter-plugins-dependencies` | File | Snapshot of plugin relationships; auto-generated by tooling. |
| `eunoia.iml` | File | IntelliJ module descriptor. |
| `README.md` | File | This document. |

## Cloud deployment (current project notes)

- **SSH / code path example**: `/home/ubuntu/Eunoia`.
- **Domain**: `www.eunoia5.top` (can be used alongside IP; for HTTPS Web voice chat, prefer same-origin + Nginx — see `server/voice-match/DEPLOY.md`).

## Run the Flutter app locally

```bash
flutter pub get
flutter run
```
